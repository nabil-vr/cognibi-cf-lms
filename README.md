# Adapt CF-LMS (prototipe)

Prototipe satu-berkas (`index.html`) untuk **Adapt CF-LMS**: LMS adaptif berbasis *cognitive friendly* (sains SMA, topik sinaps/potensial aksi dan pembuluh darah).

Buka `index.html` di peramban. Alur: onboarding (bahasa, peran, preferensi) → landing 3D → masuk/daftar → LMS sesuai peran (siswa, guru, peneliti, admin).

Catatan: three.js (r128) dan Google Fonts dimuat dari CDN; perlu internet.
